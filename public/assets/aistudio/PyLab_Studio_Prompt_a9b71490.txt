مشروع PyLab Studio

إنشاء بيئة تطوير Python احترافية ومتكاملة لنظام Android

أريد منك إنشاء تطبيق Android احترافي متكامل باسم PyLab Studio، مستوحى من Pydroid 3، ليكون بيئة تطوير Python حقيقية ومستقلة على الهواتف والأجهزة اللوحية.

المطلوب إنشاء بديل عملي ومتطور لـ Pydroid 3، يوفر محرر أكواد احترافياً، ومفسر Python حقيقياً، ومدير مكتبات، وTerminal، ومدير ملفات ومشروعات، وأدوات Debugging، مع إمكانية تشغيل البرامج محلياً دون الاعتماد على خدمات سحابية.

مهم جداً: لا أريد أي ميزة ذكاء اصطناعي داخل التطبيق. لا تضف AI Assistant أو Chatbot أو أي تكامل مع نماذج الذكاء الاصطناعي أو خدمات API. التطبيق مخصص لبرمجة Python التقليدية فقط.

ثانياً: اختيار التكنولوجيا والبنية التقنية

أنشئ تطبيق Android Native حقيقياً، وليس موقعاً إلكترونياً أو WebView مغلفاً داخل APK.

اختر التكنولوجيا المناسبة لبناء التطبيق، مع مراعاة توافقها مع Android وإمكانية تشغيل Python فعلياً.

ادرس الخيارات التالية:

- Kotlin أو Java لتطوير Android Native.
- Chaquopy لدمج Python داخل التطبيق.
- Python-for-Android عند الحاجة إلى بيئة تشغيل أوسع.
- Android NDK عند الحاجة إلى مكتبات Native.
- SQLite لحفظ بيانات التطبيق.
- محرر أكواد حقيقي يدعم Syntax Highlighting.
- Android Storage Access Framework لإدارة الملفات.

اختر الحل الذي يوفر أفضل توافق بين تشغيل Python وإدارة المكتبات وحجم التطبيق واستقراره.

لا تفترض أن جميع الخيارات تعمل معاً تلقائياً. تحقق من توافق الإصدارات والأدوات قبل اعتماد البنية.

يجب أن تكون بنية المشروع Modular، بحيث يمكن تطوير كل جزء بصورة مستقلة.

خامساً: Python Runtime – محرك Python الحقيقي

هذه أهم وظيفة في المشروع.

يجب دمج مفسر Python حقيقي داخل التطبيق، يعمل محلياً على Android.

لا تستخدم أي خدمة سحابية لتنفيذ الأكواد.

لا تستخدم محاكاة لنتائج التنفيذ.

لا تعتمد على API.

يجب أن يحتوي التطبيق على Python Runtime مدمج ومجهز للعمل بعد تثبيت التطبيق.

الوظائف المطلوبة

- تشغيل ملفات Python.
- تشغيل أكواد متعددة الأسطر.
- تشغيل المشروعات متعددة الملفات.
- دعم Python Modules.
- دعم Python Packages.
- دعم الاستيراد Import.
- دعم Classes وFunctions.
- دعم قراءة الملفات وكتابتها.
- دعم JSON.
- دعم SQLite.
- دعم Exceptions.
- عرض Traceback.
- التعامل مع المدخلات Input.
- دعم العمليات الحسابية.
- دعم العمليات الطويلة.
- إيقاف البرامج أثناء التشغيل.
- إدارة العمليات.
- إظهار حالة التنفيذ.

اختبار المحرك

يجب تنفيذ الاختبارات التالية داخل التطبيق:

print("Hello World")

for i in range(10):
    print(i)

def calculate(a, b):
    return a + b

print(calculate(10, 20))

import json

data = {"name": "PyLab Studio"}
print(json.dumps(data))

import sqlite3

db = sqlite3.connect("test.db")
db.execute("CREATE TABLE IF NOT EXISTS users (name TEXT)")
db.execute("INSERT INTO users VALUES (?)", ("Ahmed",))
db.commit()
print(db.execute("SELECT * FROM users").fetchall())
db.close()

يجب أن تعمل الاختبارات فعلياً باستخدام مفسر Python المدمج.
